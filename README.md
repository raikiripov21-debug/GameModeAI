# GameModeAI

  Android app para optimizar el rendimiento en juegos usando Shizuku.

  ## Funciones
  - Activa/desactiva modo juego con un botón
  - Muestra RAM disponible en tiempo real
  - Servicio en segundo plano (Foreground Service)
  - Aplica optimizaciones de animación via Shizuku
  - Guarda el estado con SharedPreferences

  ## Requisitos
  - Android 7.0+ (API 24)
  - Shizuku instalado y activo

  ## Compilar
  El APK se genera automáticamente con GitHub Actions en cada push.
